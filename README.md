# OOPLab2 — лабораторна робота 3.2, варіант 4

Консольний навчальний проєкт на C# для .NET 8.0. Вимоги взято з наданої методички: клас `Circle`, шість прикладів, масив, узагальнена й неузагальнена колекції, узагальнене бінарне дерево, порівняння та власний прямий обхід `preorder`.

## Запуск

У терміналі VS Code відкрийте папку проєкту й виконайте:

```powershell
dotnet run --project .\OOPLab2.csproj
```

Перевірити збирання окремо можна командою `dotnet build .\OOPLab2.csproj`.

## Структура

- `Circle.cs` — властивості, обчислення площі й довжини кола, перевірка радіуса та `IComparable<Circle>`.
- `CircleCollections.cs` — додавання, пошук і видалення для масиву (масив після додавання/видалення створюється заново).
- `CircleRadiusComparer.cs` — окремий `IComparer<Circle>` для сортування.
- `BinarySearchTree.cs` — узагальнене дерево пошуку й власний ітератор `IEnumerator<T>` з прямим обходом preorder: вузол, ліве піддерево, праве піддерево.
- `Program.cs` — шість демонстраційних кіл та приклади операцій із колекціями, сортуванням і деревом.

Для пояснення на захисті: масив має фіксований розмір; `List<Circle>` перевіряє тип елементів під час компіляції; `ArrayList` зберігає елементи як `object`, тому потребує приведення типу. Обхід preorder відвідує спочатку вузол, потім ліве й праве піддерева. Для початкових радіусів `3, 1, 5, 2, 4, 6` він виводить `3, 1, 2, 5, 4, 6`. Радіус є унікальним ключем дерева, тому друге коло з таким самим радіусом не додається.
